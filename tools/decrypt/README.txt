HOW TO OPEN THE DOCUMENT
========================

You have been given these files because someone has arranged for an
important document to be emailed to you if something happens to them.
Keep these files, and the password you were given, somewhere safe.

When the email comes, its attachment (a file whose name ends in .dmh) is
locked. You need the password to open it. The password is never sent by
email: you were given it separately. Never send it to anyone by email.

Use a computer rather than a phone, and use ONE of these two ways.


1. decrypt.html (the easiest)
-----------------------------

  1. Save the email's attachment to your computer.
  2. Double-click decrypt.html. It opens in your web browser.
  3. Choose the attachment (or drag it onto the box), type the password,
     and press Open.
  4. The opened document is saved to your Downloads folder.

Nothing is sent over the internet: the page works on its own.


2. The open-document program
----------------------------

Pick the one for your computer:

  Windows (most PCs):              open-document-windows-amd64.exe
  Windows on an ARM laptop:        open-document-windows-arm64.exe
  Mac with an Apple chip (2020 on): open-document-darwin-arm64
  Mac with an Intel chip:          open-document-darwin-amd64
  Linux:                           open-document-linux-amd64 (or -arm64)

  1. Save the email's attachment to your computer.
  2. Windows: drag the attachment onto the program.
     Mac or Linux: start the program, drag the attachment into its window,
     and press Enter.
  3. Type the password and press Enter. (Nothing shows as you type.)
  4. The opened document is saved next to the attachment.

Windows may say the program is from an unknown publisher: choose
"More info", then "Run anyway". If a Mac won't open the program, use
decrypt.html instead.


If it doesn't work
------------------

"That password didn't open it": check the password with the person who gave
it to you. Capital letters and dashes matter.

If you have lost the password or these files, ask the family, executor or
solicitor of the person who arranged this.
